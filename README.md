# esempio-flusso

Progetto d'esempio per provare il flusso di sviluppo assistito da AI: brief nel repo, sviluppatore su branch, gate automatico, merge a gate verde.
L'obiettivo finale è un piccolo strumento da riga di comando che normalizza i nomi dei file.

Test in locale: `pip install -r requirements-dev.txt` e poi `python -m pytest`.

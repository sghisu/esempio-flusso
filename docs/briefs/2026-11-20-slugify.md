# Brief: funzione slugify
2026-11-20 · Classe A · esempio-flusso
Branch di lavoro: task/slugify · Stato: aperto

## Obiettivo
Aggiungere la funzione `slugify(testo: str) -> str`, che trasforma un nome in una forma normalizzata adatta a un nome di file. Servirà alla futura rinomina in blocco dei file.

Regole:
- tutto minuscolo;
- lettere accentate ridotte alla lettera base (`è` diventa `e`);
- ogni sequenza di caratteri che non siano lettere latine o cifre diventa un solo trattino;
- nessun trattino all'inizio o alla fine;
- se non resta nulla, il risultato è la stringa vuota.

Esempi: `slugify("Città Vecchia 2024")` dà `citta-vecchia-2024`; `slugify("  --Foto__Mare!! ")` dà `foto-mare`; `slugify("日本")` dà `""`.

## Contesto e vincoli
- Codice in `renamer/slug.py`, test in `tests/test_slug.py`.
- Solo libreria standard (`unicodedata`, `re`).
- Non toccare `renamer/cli.py`.
- Funzione pura: nessuna lettura o scrittura di file.

## Criteri di accettazione
- Verificabili dall'agente: `python -m pytest` verde, con test per i tre esempi sopra, per stringa vuota, per solo simboli, per cifre e per più separatori consecutivi.
- Verificati dall'operatore in locale: `python -c "from renamer.slug import slugify; print(slugify('Città Vecchia 2024'))"` stampa `citta-vecchia-2024`.

## Sicurezza
Input non fidato: i nomi dei file arrivano dall'esterno. Il risultato contiene solo `a-z`, `0-9` e `-`: mai punti, barre o altri separatori di percorso, così non può generare percorsi relativi. Nessun segreto coinvolto. Punto OWASP rilevante: validazione dell'input.
